## 一、CodeArts Req 工作项

### Story 条目

```

  {{具体内容}}
  ## 完成标准
  {{完成标准}}
```

## 二、分支与提交

**分支名**：`{{type}}/s{{N}}-{{Story号}}-{{简述}}`

从 develop 拉取：
```bash
git checkout develop
git pull
git checkout -b {{type}}/s{{N}}-{{Story号}}-{{简述}}
```

**提交规范**：`{{type}}({{scope}}): {{subject}}`
