# 飞书多维表格字段规范

> 本文件定义 agile-sprint-assistant 输出的飞书多维表格字段结构。Skill 不调用飞书 API，只生成可直接粘贴的字段定义与表格内容。

## 粘贴格式说明

飞书多维表格支持从 Markdown 表格/TSV 直接粘贴。本 Skill 输出标准 Markdown 表格，用户复制后粘贴到多维表格首行，飞书会自动识别列。

## 迭代计划表（Phase 1 输出）

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| Story ID | 文本 | 需求编号 | S-101 |
| 标题 | 文本 | Story 标题 | 用户列表分页 |
| 描述 | 多行文本 | 验收标准 | 见 AC |
| 优先级 | 单选 | P0/P1/P2/P3 | P1 |
| 故事点 | 数字 | 估算点数 | 5 |
| 迭代 | 单选 | 迭代号 | Sprint-26 |
| 状态 | 单选 | 待开始/进行中/已完成 | 待开始 |
| 负责人 | 人员 | 领取人 | （Phase 2 填） |
| 依赖 | 关联 | 前置 Story | S-100 |
| 风险 | 多选 | 无/技术/依赖/资源 | 依赖 |

## 任务表（Phase 2 输出）

| 字段 | 类型 | 说明 |
|------|------|------|
| 任务 ID | 文本 | T-201 |
| 所属 Story | 关联 | 指向迭代计划表 |
| 子任务标题 | 文本 | 如"设计列表接口" |
| 技能域 | 单选 | 前端/后端/测试/设计 |
| 预估人日 | 数字 | ≤1 |
| 负责人 | 人员 | 推荐领取人 |
| 状态 | 单选 | 待领取/进行中/已完成 |
| 排序 | 数字 | 建议执行顺序 |

## 回顾文档结构（Phase 4 输出）

飞书文档（非多维表格）格式：

```
# Sprint-{N} 迭代回顾（{起止日期}）

## 一、迭代概览
- 计划故事点 / 完成故事点 / 完成率
- 计划 Story 数 / 完成 / 滚动到下迭代
- 流水线：构建成功率 / MR 平均合并时长 / 缺陷数

## 二、燃尽图解读
（形态 + 原因）

## 三、做得好（Continue）
## 四、需改进（Stop / Start）
## 五、阻塞与根因
## 六、改进 Action（含 Owner + 验证方式）
## 七、下迭代建议
```

## 看板列建议（飞书项目）

待办 → 进行中 → 待 Review → 待测试 → 已完成。状态流转由飞书项目承载，本 Skill 不重复定义。
